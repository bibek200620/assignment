# Submission checklist

**Bibek · SCA24CA0016 · BCA Semester V · Section A**

## Included

- Complete React and Express source code.
- MongoDB models and persistent local database configuration.
- JWT authentication and protected customer/admin routes.
- Product CRUD and cart CRUD.
- Customer cart, demo checkout, and order history.
- Demo product seed and customer/admin accounts.
- `.env.example`; actual `.env` is deliberately excluded from the ZIP.
- Root README with setup and run instructions.
- API reference, editable project report, viva/demo guide, and verification record.
- Submission report PDF with student/course details and actual screenshots.
- Sixteen automated API integration tests.

## Before presenting

1. Start Docker Desktop.
2. Extract the source ZIP and open its folder in a terminal.
3. Run `npm ci`, `npm run setup`, and `npm run dev`.
4. Open `http://localhost:5173`.
5. Read `docs/VIVA_AND_DEMO.md` and practise the customer/admin workflows.
6. Submit the source ZIP and PDF according to the faculty's preferred submission channel.

The supplied brief does not require a hosting URL or a video. Those are not included. Check any separate classroom instructions before submitting.
